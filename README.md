# 爱时间 Windows 1.2

Windows 原生学习专注应用。界面按本机全局 `landing-page-design` 设计规范重构，并把每日编程计划、题目、允许应用、实际进程与强制专注合并到同一个入口。

## 默认学习计划

- 每天 10:00 更新编程实操：固定一旧一新两题，约 15 分钟。
- 工作日 18:00 进入当天训练。
- 周一、周三、周五：Python 主线之外增加 C 语言，熟练后衔接 C++ 与软件设计师。
- 周二、周四：增加生物信息学 / AIDD。
- 周六、周日：独立周末计划，12:00 提醒；60 分钟知识学习 + 120 分钟实操。
- 周日扩展部分优先复盘本周真实错题。
- Day 进度只在完成并验收后推进，不因自然日自动跳过。

当前 Day 从 `D:\PythonPractice\DayNN_YYYY-MM-DD\task.txt` 自动读取。首页直接显示旧题、新题、当天扩展，以及每项建议使用的应用和进程。

## 自动应用范围

程序按当天计划自动构建本轮 exe 白名单。目前本机已检测到：

- PyCharm：`pycharm64.exe`
- Python：`python.exe`
- Visual Studio Code：`Code.exe`

C/C++ 编译器未在常见路径检测到时会明确显示“缺失”，不会伪装为可用。用户手动添加的额外应用单独保存，不会覆盖每日自动计划。

识别按完整 exe 路径进行，不仅按文件名。正式开始后本轮允许范围、时长和循环固定，到时自动恢复。

## 强制专注

锁定期间窗口分三类：

- **可以使用**：本轮允许的 exe（按完整路径）；它们安装目录里的组件（如 `D:\conda\envs\*\python.exe`、IDE 自带工具）；由允许应用或爱时间启动的开发运行时（python / cmd / PowerShell / 编译器 / git 等）。
- **始终可用**：输入法（微软拼音 ChsIME、TextInputHost，以及在系统注册过的第三方输入法目录）。Shift、Ctrl+Space、Win+Space 都能切换输入法。
- **隐藏**：其余带标题的窗口（包括 Windows Terminal），程序在后台继续运行，结束后按原位置恢复。锁定界面会列出已隐藏的程序。

操作方式：

- 计时面板列出允许应用；右下角计时条可拖动，“切换应用 ▾”直接列出已打开窗口和可打开的应用。Alt+Tab 只在可用窗口之间切换；切到不可用窗口会自动回到计时面板。
- 在锁定界面打开 Python 时，用独立控制台窗口，工作目录是当天的 Day 文件夹。
- 开始时先完整显示“正在准备”界面，再启动恢复进程和窗口守卫；需要隐藏的窗口只写一次恢复记录，减少卡顿。
- 倒计时使用 Windows 单调时钟，修改系统日期不能提前结束；睡眠期间不累计。15 秒试锁不计入统计。
- 主程序异常退出或无响应时，恢复进程负责恢复被处理的窗口。
## 边界

这是 Windows 普通用户会话内的强制专注，不是内核级考试机或管理员级 Kiosk。不能承诺阻止 Ctrl+Alt+Del、安全桌面、管理员结束进程、关机/重启、驱动或独占反作弊输入。遇到无法可靠覆盖或取得前台的状态会停止本轮并恢复，不修改系统安全设置强行绕过。

## 界面

左侧导航 + 右侧内容，按屏幕 DPI 缩放（125% / 150% 下不再截字）。

1. **今天**：Day 标签、题目标题、距开始时间的倒计时；一键开始（工作日 15 分钟，周末 3 × 60 分钟）、扩展、试锁。
   今日清单把 task.txt 中的【旧知识复习】【新知识进阶】和当天扩展分开显示，可逐项勾选完成（按日期保存），悬停可看验收条件，“打开题目”直接定位 task.txt。
2. **编程计划**：本周一到周日节奏，今天高亮并显示每天实际专注分钟；设置工作日轮数、休息、临时待办时长、托盘提醒、开机后台启动。
3. **待办**：临时任务，可直接“专注 N 分”或删除。
4. **应用范围**：查看自动允许应用，并添加额外 exe。

## 运行逻辑

- 周末计划按 3 轮各 60 分钟运行：第 1 轮知识学习，第 2、3 轮实操，轮间按设置休息；记录里分别标注。
- 一轮全部完成后询问是否把旧题/新题标记完成（只有通过验收才勾选）。
- 关闭窗口默认留在托盘：工作日 10:00 提示题目、18:00 提醒开始，周末 12:00 提醒；已完成或超过 3 小时的提醒不再弹出。
- 跨过零点自动切换到新一天的计划；再次双击快捷方式会唤出托盘中的窗口。
- `--background` 启动时只进托盘（用于开机启动，默认关闭，可在“编程计划”页开启）。
## 数据

设置、待办和记录位于 `%LOCALAPPDATA%\AiTimeWindows`。保存使用临时文件与原子替换并保留上一版备份。恢复日志只保存窗口身份和位置，不保存窗口正文、密码或屏幕内容。

## 构建

`src/` 为 C# 5 源码，使用 Windows 自带 .NET Framework 编译器：

```powershell
.\Build.ps1
.\Install.ps1
.\bin\AiTime.exe --self-test .\validation\unit-redesign.json
.\bin\AiTime.exe --integration-test .\validation\integration-redesign.json
```

自动集成测试不会偷偷抢前台；若测试窗不是当前前台，会停在准备检查并报告未完成。实际产品的 15 秒试锁可用于当前桌面环境的最终兼容检查。
